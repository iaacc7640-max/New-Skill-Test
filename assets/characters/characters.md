# ClearCut History — characters

All characters are ClearCut originals: flat vector, about 3.5 heads tall (360-unit viewBox, head radius 44),
dot eyes, eyebrow line, small mouth, outlines no heavier than 2 px. Generated by `tools/make-kit.mjs`.

**Channel narrator voice:** Kokoro `bm_george` (British male), via `npx hyperframes tts`. Pilot used speed 1.1.

## Rig contract (every character)

ViewBox `-130 -350 260 360`, feet at y = 0. Groups carry `class="rig-<part>"` and `data-pivot="x y"`
(SVG user units, used as GSAP `svgOrigin`). No ids, so a file can be inlined many times in one page.

| Group | Pivot | Notes |
|---|---|---|
| `rig-root` | 0 0 | whole body; walk bob |
| `rig-legL`, `rig-legR` | ±17, -118 | hip |
| `rig-armL-upper`, `rig-armR-upper` | ±40, -205 | shoulder; contains `-lower` |
| `rig-armL-lower`, `rig-armR-lower` | ±46, -158 | elbow; hand is `rig-handL/R` |
| `rig-torso` | 0, -112 | breathing scaleY |
| `rig-head` | 0, -214 | neck; contains face and hat |
| `rig-face` | 0, -262 | slides sideways for head turns |
| `rig-eyes` | 0, -266 | blink scaleY |
| `rig-brows` | 0, -280 | react / frown (y) |
| `rig-mouth` | face x, -240 | `.m0` closed, `.m1` open, `.m2` wide |

Motions live in `assets/characters/rig.js` (`window.ClearCutRig`): `rest`, `idle` (1–2 % breathing),
`blink` (every 3–5 s, seeded), `talk` (3 mouth shapes), `pose`, `point`, `gesture`, `walk` (4 keys per
stride), `turnHead`, `react`, `frown`, `crowd` (seeded bob/sway for `<use>` armies). All finite and seeded:
any frame is a function of timeline time.

`R` = viewer's right. Positive rotation is clockwise. `point(tl, el, t, "R")` swings the R arm out to the right.

## Design notes and simplifications
- Tricorne instead of the shako named in the style guide: the shako is a later (c. 1800) headdress; a 1757 soldier wore a tricorne.
- Sepoy turban styling is simplified; it is not a regimental reconstruction.
- Siraj's and Mir Jafar's looks are invented (no reliable likeness is implied).
