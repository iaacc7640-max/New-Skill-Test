# ClearCut History asset kit

Built once, reused every episode. Regenerate with `npm run kit` from the repository root.

- `characters/` rigged character SVGs, `rig.js` motion library, `characters.md`
- `sets/` layered set SVGs (`set-sky`, `set-clouds`, `set-far`, `set-mid`, `set-ground`, `set-fg`) and `props/`
- `maps/` Bengal base map (Natural Earth coastline via `world-atlas`, hand-simplified historical region) + projected city coordinates
- `ui/` `ui.css` (label chip, name card, stamp, trust tags, MAP SIMPLIFIED, versus, stat, title, end card, grade layers), `grain.png`, `paper.png`
- `audio/` sound effects and score stems synthesised in code (`tools/audio_kit.py`)
- `fonts/` Bebas Neue, Inter, EB Garamond from `@fontsource` (OFL)
- `palette.json`
